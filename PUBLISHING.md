# AirRecipes — онлайн-каталог

Публічний файл `catalog.json` містить лише опубліковані рецепти. Код Android-застосунку лишається приватним.

## Формат

```json
{"schemaVersion":1,"catalogVersion":1,"recipes":[],"deletedIds":[]}
```

- Збільшуй `catalogVersion` при кожній публікації **або видаленні**.
- `recipes`: масив об'єктів із експорту «Для вбудованого каталогу» AirRecipes.
- Кожен онлайн-рецепт має постійний унікальний ID з префіксом `online-`, наприклад `online-chicken-wings-001`.
- Зараз синхронізація переносить текст рецептів без фотографій. Фотографії додамо окремо з ліцензіями.

## Додавання

1. Експортуй власний рецепт із AirRecipes.
2. Перевір походження, інструкції, час, температуру та права на вміст.
3. Додай об'єкт у масив `recipes`, присвой постійний `online-...` ID.
4. Збільш `catalogVersion`, створи Pull Request, перевір JSON.
5. Після об'єднання в `main` телефон зможе завантажити рецепт.

## Видалення назавжди з загального каталогу

1. Прибери рецепт із масиву `recipes`.
2. Додай його ID до `deletedIds`, наприклад `"online-chicken-wings-001"`.
3. Збільш `catalogVersion` та опублікуй зміни.

Після синхронізації рецепт зникне з загального каталогу користувачів. Якщо користувач його редагував або додав у вибране, його копія збережеться як особистий рецепт. Не вилучай записи з `deletedIds` без потреби: вони захищають від випадкового повторного додавання старої версії.

Публічна адреса: https://raw.githubusercontent.com/Estonec777/AirRecipesCatalog/main/catalog.json

Не публікуй особисті дані, токени, локальні шляхи фотографій чи неперевірені матеріали.
