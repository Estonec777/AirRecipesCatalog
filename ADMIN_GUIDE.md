# AirRecipes — перша версія панелі керування каталогом

Файл `admin.html` — автономна сторінка для підготовки змін у `catalog.json`.
Вона не використовує пароль або токен GitHub і не може самостійно публікувати зміни.
Сторінка доступна для перегляду в публічному репозиторії, **але змінювати репозиторій
може лише користувач з відповідними правами GitHub**.

## Як користуватися

1. Завантаж `admin.html` на комп'ютер і відкрий його в браузері.
2. Натисни **«Завантажити чинний каталог»**. Якщо браузер блокує мережеве
   завантаження локальних сторінок, завантаж `catalog.json` із GitHub і натисни
   **«Відкрити JSON із комп’ютера»**.
3. Створи, відредагуй або видали рецепт. На телефоні користуйся вкладками
   **«Основне»**, **«Продукти»**, **«Кроки»**, **«Фото»**.
   Кожну зміну збережи кнопкою **«Зберегти рецепт»**. Повідомлення про помилку
   з’явиться безпосередньо біля кнопки.
4. Фото WebP (до 1 МБ) завантаж окремо у `images/` через GitHub. Для зміненого
   фото використовуй нову назву файла, наприклад `dish-v2.webp`.
5. Натисни **«Завантажити catalog.json»** — файл матиме збільшену `catalogVersion`.
6. У GitHub відкрий `catalog.json` → редагування → заміни вміст вмістом завантаженого
   файла. Створи Pull Request, перевір зміни та об'єднай у `main`.
7. У застосунку AirRecipes натисни **«Оновити рецепти»**.

## Важливо

- Перед редагуванням завжди завантажуй **поточний** каталог.
- Після публікації ID рецепта змінювати не можна.
- Видалений опублікований рецепт потрапляє в `deletedIds`, щоб програма могла
  прибрати його з загального каталогу на телефонах.
- Панель автоматично зберігає поточний каталог і чернетки у локальне сховище
  браузера, якщо воно доступне. При повторному відкритті **того самого файла
  в тому самому браузері** локальна робота відновиться. Приватний режим,
  очищення даних браузера, інший файл або пристрій можуть стерти цю копію.
  Надійна резервна копія — експорт `catalog.json` після натискання «Зберегти рецепт».
- Натискання «Зберегти рецепт» **не публікує** його для інших користувачів.
  Публікація відбувається лише після оновлення `catalog.json` у GitHub.
- Не додавай до каталогу приватні дані або фотографії без права на публікацію.
- Час і температура для аерогриля потребують перевірки. У описі позначай,
  якщо рецепт поки що не випробуваний.

Це мінімальна безпечна версія без автоматичної авторизації й запису. Згодом можна
створити окрему захищену панель з серверною авторизацією та прямою публікацією.
